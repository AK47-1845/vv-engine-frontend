# Design Brief

VERIFIED DESIGN CHECKPOINT: Research completed; design implemented in the first hero and token system. See design-intel/README.md and site/src/app/site.css.

Concept: Instrument-grade trust. A dark physical-AI test instrument, not a generic AI landing page. Genuity Verify remains the product name from the existing project.

Palette: #0c0f10 near-black, #f2f5f3 text, #83ece4 cyan signal, #bfdea1 pass, #ffa18b fail; evidence paper #eef1ed. Typography: local Geist + JetBrains Mono, fixed responsive sizes and zero letter-spacing. Motion: purposeful 200ms feedback, GSAP pipeline progress, Lenis scrolling only without reduced-motion preference.

Implemented sections: live verification hero, failure-injection demo, pinned four-stage pipeline, evidence/report view, regulatory timing, founder/build status/pilot ask, request-pilot dialog and explicitly unrecorded demo placeholder. Mobile uses a lightweight animated trace with optional 3D; desktop uses Three.js.

Signature interactions: shared robot trace plus streamed gates; deterministic failure injection with an explained verdict; one visual transforming through the evidence pipeline.

Claims: no assertion that the product proves complete physical safety, issues certificates, or has customers/pilots not supplied by the user.
