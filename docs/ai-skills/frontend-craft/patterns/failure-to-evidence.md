# Failure To Evidence

Problem: A guardrail pitch becomes generic when failures change only a decorative status badge.

Use a pure model, as in `site/src/lib/demo.ts`, to derive every gate from the chosen perturbation. Render the altered trace, metric, threshold, decision and exported evidence together. Keep a reset to the deterministic nominal case. `FailureLab.tsx` owns presentation state; `Evidence.tsx` presents the same model in a report vocabulary.

Test each failure's intended gate, not only the overall verdict. Test reset, download, reduced motion and malformed/no-op paths before claiming the interaction works. Keep SHA256 integrity distinct from signatures. The synthetic origin and limitations must survive export.

Pitfalls: overlapping evaluation timers, stale labels, fake risk percentages, uncalibrated gates presented as safety limits, and an export that silently loses its qualification.
