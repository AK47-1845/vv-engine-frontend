# Anti-Slop Rules

| Cheap Pattern | Required Fix |
| --- | --- |
| Decorative sphere labeled "AI" | Render the actual robot/trace or a truthful static asset |
| A safety percentage with no definition | Show per-gate measurements, thresholds and missing evidence |
| Every section inside a rounded card | Use full-width bands, grids and hairline separators |
| Fake company logos or certification stamps | Use verified attribution or explicit [REPLACE] placeholders |
| Dark media nobody can inspect | Light the subject and verify pixel coverage and composition |
| Endless animated decoration | Give motion a state or narrative purpose and pause controls |
| Desktop UI simply scaled down | Recompose mobile and measure longest controls and headings |
| Contact form with pretend success | Real approved destination or clearly local unsubmitted draft |
| Build success called visual acceptance | Inspect screenshots and run interaction/accessibility tests |
